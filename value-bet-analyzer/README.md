# Automatic Stats Collection Guide

## 🚀 How It Works

Instead of manually typing stats, this tool **automatically scrapes** team data as you browse!

## 📋 Quick Start

### Step 1: Run the Stats Collector
Double-click **`collect_stats.bat`**

### Step 2: Browser Opens Automatically
- Opens FBref.com
- You're ready to collect stats!

### Step 3: Navigate to Team Pages
1. Search for a team (e.g., "Arsenal")
2. Click on the team page
3. **Stats are automatically extracted!** ✅
4. Repeat for other teams

### Step 4: Close Browser When Done
- All stats are saved to `data/team_stats.csv`
- Ready to use in the betting bot!

### Step 5: Run the Betting Bot
Double-click **`run_bot.bat`** to analyze matches with real data!

## 🎯 What Gets Scraped

For each team page you visit:
- ✅ Last 5 match results (W/D/L)
- ✅ Goals scored (total in last 5)
- ✅ Goals conceded (total in last 5)
- ✅ Automatically saved to CSV

## 💡 Pro Tips

1. **Visit both teams** in a match before running the bot
2. **Use FBref.com** - Best for detailed stats
3. **Check console** - See what's being scraped in real-time
4. **Data persists** - Collected stats are saved for future use

## 🔄 Workflow Example

**Analyzing Mexico vs South Africa:**

1. Run `collect_stats.bat`
2. Browser opens → Search "Mexico"
3. Click Mexico team page → **Auto-scraped!** ✅
4. Search "South Africa"  
5. Click South Africa page → **Auto-scraped!** ✅
