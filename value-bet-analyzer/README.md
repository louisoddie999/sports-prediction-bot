# Value-bet analyzer

An experimental analysis module that compares model probabilities with bookmaker-implied probabilities after removing the estimated margin.

`value_bet_analyzer_v7.3.py` includes:

- proportional probability normalization
- configurable expected-value thresholds
- Poisson and Dixon-Coles adjustments
- form and head-to-head inputs
- CSV and JSON reporting

The included CSV and JSON files are development fixtures, not current recommendations or proof of profitability.

Run the analyzer only after reviewing its configuration and supplying fresh, legally obtained data. Historical fit is not a guarantee of future performance.
